Limitations

Some pages can't be read

Browser pages such as the Chrome Web Store and Chrome's settings can't be read by any extension. On job boards embedded in another site, open the posting in its own tab.

Connecting Gmail is waiting for Google

Google is reviewing Rolestash's read-only Gmail access. Until it approves, Connect Gmail isn't offered (mailboxes connected earlier keep working), and Outlook can't be connected yet. Automatic status updates work today by forwarding your job emails: Account → Automatic status updates.

Chrome on desktop only

Rolestash runs in Google Chrome and other Chromium browsers that install from the Chrome Web Store. Edge and Firefox versions are planned. On a phone, Pro includes a web board.
